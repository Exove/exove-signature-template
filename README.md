# Exove signature template

The repository is used for hosting HTML-files (`signature.html` for Apple Mail and `thunderbird.html` for Mozilla Thunderbird). The files are available through Github pages ([for Apple Mail](https://exove.github.io/exove-signature-template/signature.html) and for [Mozilla Thunderbird](https://exove.github.io/exove-signature-template/thunderbird.html)).

The up-to-date guide for adding signature is available in [Google Drive](https://docs.google.com/document/d/1D2_CJ9sVD-7PCqL2C_YQ14nkYKbJCnkgXahE41g8Lnc/edit?tab=t.0).

## Thunderbird to Apple mail

Seems that there have been issues with styling when sending mail with signature from Mozilla Thunderbird to Apple mail. 
This has resulted in situations where the logo is very large and text is minimal. Apparently this has something to do with the styling.

The next person who modifies the signature (especially in Thunderbird but also in Apple mail), remember to verify whether the changes really work fine (Thunderbird -> Thunderbird, Thunderbird -> Apple mail, Apple mail -> Thunderbird, Apple mail -> Apple mail).
